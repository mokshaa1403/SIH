      02

      Specialist workflows

      One controller, four replaceable analysis modules.

      VQA

      Scene understanding

      Answers controlled questions about visible land-cover evidence.

      GRD

      Visual grounding

      Highlights water, vegetation, built-up and bare-land regions.

      CHG

      Temporal change

      Creates an explainable difference mask from aligned image pairs.

      FUS

      Optical–SAR fusion

      Combines complementary optical and radar signals with explicit weights.

      03

      Designed around documented gaps

      A small local system that complements Bhuvan, Bhoonidhi and VEDAS.

      Question first

      The user asks a supported question. The router chooses the workflow and records why.

      Evidence required

      Grounding and change tasks return a pixel mask instead of an unsupported text-only claim.

      Local by default

      Uploaded images remain on this server. No commercial catalogue or external inference API is required.

      Open input

      Ordinary PNG and JPEG images work now. Geospatial adapters can later add governed ISRO products.

      Failure visible

      Confidence factors, warnings and refusal behavior expose weak or unsupported cases.

      Replaceable models

      The registry separates routing, scene classification, grounding, change and sensor fusion.
